Project Overview

This project aims to accurately predict which suppliers are at risk of being lost, allowing the company to take preventive action in advance. By analyzing historical supplier data, the model identifies key risk factors and provides early warnings of supplier attrition.

Key Results

Key results and visualizations from the project are presented below:

ROC Curve Comparison

The ROC curve illustrates the trade-off between true positive rate and false positive rate. Our model's curve reaches the top-left, indicating excellent performance (AUC = 1.00).

XGBoost Confusion Matrix

The confusion matrix shows that the model correctly identifies almost all at-risk suppliers. There are very few false alarms or missed detections, reflecting high recall and precision.

Random Forest Feature Importance

The Random Forest model's feature importance plot ranks the input features by their influence on predicting supplier loss. It highlights which factors are most significant in determining the outcome.

XGBoost Feature Importance

The XGBoost model's feature importance chart similarly identifies key predictive features. The top factors align with the Random Forest results, reinforcing their importance in predicting supplier loss.

SHAP Summary Plot

The SHAP summary plot explains how each feature affects the model's predictions. It shows which features push predictions toward higher risk (red) or lower risk (blue), aiding interpretability.
