Supplier Loss Prediction Model

Machine-learning-based early warning system for supplier churn  |  AUC 1.00 · 99 % Recall · SHAP-driven insights

Download PDF Report

Project Abstract

This project compares Logistic Regression, Random Forest and XGBoost models to forecast supplier loss events at the firm-year level. On the hold-out test set, XGBoost achieved an AUC of 1.00 and captured 99 % of actual loss cases with minimal false alarms. SHAP analysis reveals that the prior supplier count (supplier_num_lag1), current supplier count and the Country-Year context are the strongest drivers of risk.
